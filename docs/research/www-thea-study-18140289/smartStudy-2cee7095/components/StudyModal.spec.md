# StudyModal
Reusable shell for settings, progress and session history. Source settings dialog: width500px, padding20px, radius8px, inner padding16px; background #eef1f9. Title24px regular, centered, bottom margin24px. Responsive width viewport minus32px; bounded viewport height with scrolling.
Native modal dialog provides focus containment. Escape, close button and backdrop close it; restore previous focus and body scrolling on unmount. No image assets.
