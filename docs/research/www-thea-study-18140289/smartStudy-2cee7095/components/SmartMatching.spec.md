# SmartMatching
Source layout: grid columns1fr 2fr, gap8px, card radius15px, dawn background and2px border. Padding28px desktop,24px below1200. Mobile below480 uses12px text and28px top padding for corner symbols. Heart/star/club/diamond/spade identify pairs. Symbols are local text approximations.
Select left term, then right definition. Incorrect pairing allows retry; matched pairs disable. All pairs completed records one response; any mistake marks that response incorrect. Revealing shows pair symbols and stops scoring. Five local terms maximum, unique definitions. No backend dependency.
